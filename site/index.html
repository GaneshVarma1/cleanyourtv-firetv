How it came together

From stuck to quiet.

What we tried, what failed, and what worked.

Make the launcher the Home app

Failed. Fire OS holds Home at a priority that other apps can't beat, and it refuses to disable it.

Intercept the Home key

Failed. The accessibility service got no key events on this model.

Watch for Amazon's home window

Worked. When it appears, the launcher comes up on top.

Turn off the telemetry, in batches

Worked. Each batch was checked with a screenshot, and streaming apps still open.

Reboot and test again

Worked. The watcher and the dock both came back.

Setup

Five steps. Then it's quiet.

Run these from a Mac or Linux computer on the same Wi-Fi as the TV.

01

Turn on ADB on the Fire TV

Settings → My Fire TV → About, select the device name seven times. Then Developer Options → ADB Debugging. The IP is under About → Network.

02

Get the repo and check the connection

Clone it, then probe the TV. You should see Amazon as the brand.

git clone https://github.com/GaneshVarma1/cleanyourtv-firetv.git
export TV_HOST=192.168.1.50 && tools/venv/bin/python -I tools/tv.py --probe
03

Remove the telemetry and ads

Applies the tested list. The previous state is saved, so you can undo it.

tools/disable.sh examples/amazon-fire-tv-aftdec012e/debloat.txt
04

Choose your dock

Edit dock_apps in launcher/app/src/main/res/values/config.xml with the package names you use.

05

Build and install the launcher

The script sees that Amazon holds Home, and installs in Fire mode. Press Home, and the launcher comes up.

cd launcher && TV_HOST=$TV_HOST ./build-and-install.sh

Honest notes

What it can't do.

Fire OS keeps the Home button for Amazon's launcher. So the launcher covers the home screen. It doesn't replace it.

Works

  • Telemetry, ACR, shopping and preloads off
  • Home opens the launcher, from apps and after a reboot
  • Streaming apps keep working

Expect

  • A brief flash of Amazon's home first
  • Amazon's home keeps running in the background
  • Tested on one model. Others may need other package names.
