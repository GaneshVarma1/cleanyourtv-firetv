02 · the setup

Five steps. Then it's quiet.

You run these from a Mac or Linux computer on the same Wi-Fi as the TV. Set the TV's IP once and reuse it.

Turn on ADB on the Fire TV

Settings → My Fire TV → About, select the device name seven times. Then Developer Options → ADB Debugging, and note the IP under About → Network.

Get the repo and check the connection

Clone it, make the ADB environment, and probe the TV. You should see Amazon as the brand.

git clone https://github.com/GaneshVarma1/cleanyourtv-firetv.git
export TV_HOST=192.168.1.50 && tools/venv/bin/python -I tools/tv.py --probe

Remove the telemetry and ads

Applies the tested list. Each package is disabled, not uninstalled, and the previous state is saved so you can undo it.

tools/disable.sh examples/amazon-fire-tv-aftdec012e/debloat.txt

Choose your dock (optional)

Edit dock_apps in launcher/app/src/main/res/values/config.xml with the package names you use.

Build and install the launcher

The script sees that Amazon holds Home and installs in Fire mode: Amazon's launcher stays on, and the launcher comes up when you press Home.

cd launcher && TV_HOST=$TV_HOST ./build-and-install.sh
03 · the honest part

What it can't do.

Fire OS keeps the Home button for Amazon's launcher, and won't let it be disabled. So this doesn't replace the home screen. It covers it.

What works

  • Telemetry, ACR, shopping and preload packages off
  • Home opens the launcher, from apps and after a reboot
  • Streaming apps keep working after the list is applied

What to expect

  • A brief flash of Amazon's home before the launcher covers it
  • Amazon's home keeps running in the background
  • Tested on one Fire TV model; others may need other package names
