# FIRE OS: DEBLOAT ONLY. Amazon's launcher (com.amazon.tv.launcher) holds Home at priority 950, a non-system
# app's priority and set-home-activity are both ignored, and its packages and components cannot be disabled
# ("Cannot disable a protected package"). So this launcher cannot be Home; launcher/build-and-install.sh installs
# it in Fire mode instead: it comes up over Amazon's home whenever that home appears. Details and what was tested:
# docs/TROUBLESHOOTING.md, "Fire TV (Fire OS)". This list removes Amazon's ads, telemetry and preloads.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/amazon-fire-tv-aftdec012e/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/amazon-fire-tv-aftdec012e/debloat.txt com.amazon.tv.launcher
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
